The site presents source-backed candidate excerpts, publication and retrieval metadata, an institution comparison, timeline, discovery notes, citations, and downloadable exports. The **Compare colleges** view includes a panel summary: the current candidates show workflow and award-availability differences, but not comparable campus award dates. General aid deadlines and statewide processing dates remain separate. All 55 passages are machine-located; human-accepted findings: 0. Complete PDFs and HTML sources are not mirrored here; source links open the publisher or archival copy. Review, annotation, and correction controls are unavailable in this read-only edition. The full local research app retains the original source cache and append-only review history.

The `site/` directory is the Pages deployment artifact. GitHub Actions publishes it on pushes to `main`.

The 2018–19 and 2019–20 TAMIU pages have been recovered; only the Texas Tech strategic plan remains unrecovered. Reviewer identities and private review history are excluded from every public export.
